# 記帳小幫手

手機優先的記帳 PWA。純前端（HTML/CSS/JS，無框架、無建置工具），資料存在瀏覽器的 IndexedDB，不需要帳號、不需要伺服器。

## 本機執行

用任何靜態伺服器啟動這個資料夾即可，例如：

```
npx serve expense-tracker
```

或

```
python -m http.server 8000 --directory expense-tracker
```

開啟後用手機瀏覽器（或桌機瀏覽器縮小視窗）打開該網址，選「加到主畫面」即可像 App 一樣使用，離線也能開啟。

## 功能

- 快速記帳，欄位順序是**日期 → 種類 → 評分 → 金額 → 備註**；日期在最上面一條，左右箭頭一天一天調（點日期本身會開系統日曆），記完馬上在同一頁看到月結算
- 分類管理，可自訂名稱、線條圖示與顏色（全 App 不使用 emoji）
- 消費明細列表，依月份/分類篩選
- 月結算：分類佔比圖、近 6 個月趨勢圖、預算與超支提醒（就在「記一筆」頁下半部）
- 美食評分：食物／飲料分類可以打 1–5 顆星，「評分」頁籤有排行、平均分與待評分清單
- 多人分帳：記帳時可標記「與人分帳」，只有你的份會計入月消費；「更多」頁籤裡的「分帳總覽」會算每個人欠你多少、你欠誰多少，可登記結清（純本機計算，不會跟對方的手機同步）
- 方案：一次出遊／一個計畫開一個方案，設定日期和同行的人，裡面有兩頁
  - 攜帶清單：加項目、勾選「準備好了」，可以指派誰帶什麼，也能切「依人分組」看每個人要帶的東西
  - 算帳：記下這趟每一筆花費（總金額、誰先付、誰要分、平均或自訂），自動算出每個人付了多少、該分多少，再給一份「最少轉幾次帳」的轉帳建議，按「登記結清」就能把帳沖掉
- 資料匯出／匯入（JSON 備份，含分類、支出、預算、同伴、結清紀錄、方案與攜帶清單）、匯出 CSV

## 幾個設計上的取捨

- **配色只有「深夜」一套**，沒有淺色版可切。深底是為了讓分類自己的飽和色跳出來，所以 `:root` 直接就是深色值、`color-scheme: dark`（原生日期選擇器、下拉、捲軸才會跟著變深）。要加淺色版的話，`css/styles.css` 的 `:root` 是唯一要動的地方，但 `components.css` 裡幾個寫死的值（`--color-dim`、header/tabbar 的 rgba、modal 遮罩）也要一起換成變數。
- 分類選擇器是一排橫向捲動的圓形圖示，不是格子。分類再多也只佔一排高度，代價是一次只看得到 5 個。

- 方案裡的花費就是一般的支出記錄，只是多帶了 `tripId`；記進去的 `amount` 只放「我的份」，帳單總額放在 `split` 裡，所以月結算不會被別人的份灌水（我沒有分到的花費就是 $0）。
- 方案的「怎麼喬」是多人一起淨算的最少轉帳，可能把 A 欠 B 的錢直接轉給 C；「分帳總覽」則永遠是以你為中心的兩人帳。跟你有關的結清兩邊都會沖掉，但個別對象的金額可能長得不一樣。
- 舊版的「出門清單」在資料庫升到 v4 時會自動變成方案（id 不變，清單項目照樣掛著）。舊的 `packingLists` store 留著沒刪，當作備援。

## 改東西的時候

**改完任何前端檔案，一定要推 `sw.js` 最上面的 `CACHE_VERSION`。** Service worker 對靜態檔是 cache-first，版本號沒變的話，已經裝在手機上的那份會一直吃舊的 CSS/JS——改了完全看不出來，也不會報錯。

## 注意

資料只存在這台裝置的瀏覽器裡，清除瀏覽器資料或換裝置會遺失，請定期在「更多」頁籤匯出備份。
